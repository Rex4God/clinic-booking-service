# Koya Booking Service API

## Overview

- This is a booking service api for Koya application api

## Dependencies

- MongoDB
- Mongoose

## Backend

    - API Documentation :
    - Language : Nodejs (Xpress framework)

## Feature List

- [x] Booking Service
- [x] Slot Service
- [x] API Key Service


## Database

    kind: MongoDB Atlas
    db-name : clinic-booking

## Setting up for Development

- Clone project.
- Install Node ( >= 14.0.0).
- Install yarn/npm.
- Copy .env.example to .env file
- Run yarn/npm install.
- Run yarn/npm start.

## Execute
- yarn/npm start 
- yarn/npm run dev

## Test
```
yarn/npm run test
```
